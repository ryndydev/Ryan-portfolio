# ragba.dev — Ryan Adaya's portfolio

Next.js 16 (static export) · Tailwind 4 · Framer Motion · deployed to GitHub Pages.

```bash
npm run dev     # http://localhost:3000
npm run build   # static site in ./out
```

Content lives in `content/site.ts` (personal details, stats, services, timeline) and `content/projects.ts` (case studies). Images in `public/images/`.
